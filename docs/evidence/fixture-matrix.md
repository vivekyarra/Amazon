# Fixture matrix F01–F24 (spec section 13)

Each fixture ID maps to the tests that machine-check its golden assertion. All of them run green in CI
on every push. Backend tests live in `apps/mcp-orchestrator/tests/`, browser tests in `tests/e2e/`,
and the TV emulator journey is `scripts/firetv-emulator-check.py` (CI job `firetv-emulator` in
`.github/workflows/ci.yml`). Fixture provenance is recorded in
[`packages/testing-fixtures/manifest.json`](../../packages/testing-fixtures/manifest.json).

Provenance labels:

- **SCRIPTED**: generated marker pixels, generated video and Bee-shaped utterances.
- **REAL_RECORDED_STOCK**: licensed public clips. These are not Ring footage.
- **PATCHED_TRANSPORT**: provider HTTP transport patched in-process (no network).

Nothing in this matrix is a live Ring, Bee or physical Fire TV run.

## Limits that remain visible

- **F17/F18.** These use a generated humanoid video run through real MediaPipe. Spec 11.4 permits that.
  Consented human footage would make the result stronger.
- **F19.** Session expiry is driven through the real `CameraBridge.expire/stop` cleanup path. The session
  objects and the Ring transport are scripted in-process, so no live 30 s or 60 s Ring session has expired.
- **F24.** The machine checks run on an Android TV emulator and in Chromium. The only Vega check is a
  manual session on the official Vega Virtual Device. No physical Fire TV was used.
